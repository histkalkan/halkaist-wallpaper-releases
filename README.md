# Halkaist Wallpaper — sürümler / releases

Windows 10/11 için hafif, animasyonlu duvar kâğıdı uygulaması. Bu depo yalnızca indirilebilir sürümleri içerir; kaynak kod burada değildir.

A lightweight animated wallpaper app for Windows 10/11. This repository only hosts downloadable releases; the source code is not here.

## İndirme / Download
[Releases](../../releases/latest) sayfasından / page:
- `HalkaistWallpaper-Kurulum-<sürüm>.exe` — kurulum / installer (.NET 10 Desktop Runtime x64 ve / and WebView2 gerekir / required; kurulum yönlendirir / the installer guides you)
- `HalkaistWallpaper-Tasinabilir-<sürüm>.zip` — kurulumsuz / portable (.NET gerekmez / no .NET needed)

Uygulama yeni sürümleri bu depodan denetler (günde en fazla bir kez, yalnızca haber verir).
The app checks this repository for new versions (at most once a day; it only notifies you).

Kurulum dosyaları şimdilik imzasızdır; Windows SmartScreen "Ek bilgi → Yine de çalıştır" isteyebilir.
Installers are currently unsigned; Windows SmartScreen may ask you to choose "More info → Run anyway".

Hazır görsel ve videolar yapay zekâ ile üretilmiş temsilî içeriktir. / Bundled images and videos are AI-generated.
